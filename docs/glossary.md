# Glossary

| Term | Meaning |
|---|---|
| **Basket** | What a customer is about to order: menu items and quantities, not yet priced. |
| **Line** | One menu item and its quantity within a basket or order. |
| **Category** | Main, side, drink, dessert or snack. Receipts list them in that order. |
| **Meal deal** | One main, one side and one drink for a fixed price (£6.50 by default). |
| **Promotion** | A discount based on what's in the basket (e.g. the meal deal). |
| **Loyalty tier** | Bronze, Silver or Gold. Gives a percentage off and multiplies points. |
| **Points** | Earned per whole pound paid; lifetime points decide the tier. |
| **Student discount** | 10% off for verified students, Monday to Friday. |
| **Breakdown** | The result of pricing: subtotal, each discount, total, VAT. |
| **Order** | A priced and paid-for basket, with a status (placed, preparing, ready, collected, cancelled, refunded). |
| **Line refund** | Refunding one line of a collected order, at what it actually cost after discounts. |
| **Adapter** | Code that talks to the outside world (database, payments, email) behind an interface. |
| **Smoke test** | One of the ~20 fastest, most critical tests, run on every change. |
| **ADR** | Architecture Decision Record: a short note of a decision and why it was made. |
